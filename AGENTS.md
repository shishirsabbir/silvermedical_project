# Project working instructions

## Context and continuity

Before significant work, read README.md, memory/PROJECT_MEMORY.md, memory/DECISIONS.md and memory/OPEN_QUESTIONS.md. Read the relevant analysis files rather than relying on chat history.

The project is a new medical ecommerce brand with a UK-first launch, later European expansion, Praxisdienst as benchmark, mixed UK/EU sourcing and full product-range ambition. The workspace folder name does not establish the new brand or legal operator.

## Research and documentation

- Keep project memory and analysis inside this repository.
- Record a source URL, check date and geographical/product scope for material factual claims.
- Prefer regulators, legislation, HMRC, NHS and official EU sources for requirements; competitor sites establish only that competitor's published offers.
- Distinguish confirmed user decisions, observed facts, recommendations and assumed model inputs.
- Treat GB, Northern Ireland and each European destination separately where relevant.
- Treat medical devices, IVDs, PPE, biocides, medicines and ordinary goods as separate routes; a category name is not a regulatory classification.
- A proposal to phase implementation does not remove any product category from the user's stated full-catalogue ambition.
- Never infer that licences, suppliers, insurance, NHS approval, company ownership or manufacturer permissions are in place.
- Recheck time-sensitive requirements before relying on them. Consultations and announced reforms are not enacted requirements.
- Keep sources, decisions, assumptions and open questions aligned when new information arrives.
- Do not commit credentials, customer/patient data or private supplier terms to general research notes.

## Scope of implementation

This baseline authorises research and local project documentation. It does not establish approval to publish a store, purchase stock, enter contracts, make licence applications or send external messages. Follow later user instructions for those actions. Continue ordinary local research and reversible documentation without unnecessary permission questions.
