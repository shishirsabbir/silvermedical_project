# Silver Medical · The Silver Edit

The Silver Edit is the selected homepage design. The offline preview includes desktop and mobile views, a full-window preview, and working catalogue search, filters, product details, saved products and a sample basket. Products, photography and prices are illustrative.

[Open the homepage preview](../../../deliverables/html/SILVER_MEDICAL_HOMEPAGE_MOCKUPS.html) or [download the client ZIP](../../../deliverables/Silver-Medical-Homepage-Mockups.zip).

Rebuild both files from the workspace root:

```powershell
python dev/designs/homepage-concepts/build.py
```

The storefront uses the [Silver Medical logo assets](../../../apps/storefront/README.md). Local WebP images and fonts are embedded in the preview. The [image generation prompts](assets/prompts.json), original raster assets and font licenses are in `assets/`.

The previous homepage rounds, the Medora storefront prototype and the first logo study source files are in `.local/archive/2026-11-22-design-cleanup/`.
