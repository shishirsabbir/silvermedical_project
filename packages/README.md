# Shared packages

The storefront consumes `@silver-medical/ui` through npm workspaces. The contracts and database directories describe planned package boundaries.

- [Contracts](contracts/README.md): browser-safe API schemas and types.
- [UI](ui/README.md): presentation code worth sharing across applications.
- [Database](database/README.md): server-only schema, migrations and access.

See the [development handoff](../docs/development/README.md) before adding dependencies.
