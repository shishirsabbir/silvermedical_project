# Applications

The storefront contains the working Next.js homepage and interactive design system. The admin, API and worker directories describe planned application boundaries. See the [development handoff](../docs/development/README.md).

- [Storefront](storefront/README.md): public Next.js shopping experience.
- [Admin](admin/README.md): React staff application.
- [API](api/README.md): authoritative commerce and access rules.
- [Worker](worker/README.md): proposed background processing application.
